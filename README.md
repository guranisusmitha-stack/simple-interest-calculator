# Simple Interest Calculator

A simple program/tool designed to calculate the interest accrued on a specific principal amount over a given period of time at a fixed interest rate.

## Formula Used
The simple interest is calculated using the standard formula:

$$A = P(1 + rt)$$

Where:
* **A** = Total accrued amount (Principal + Interest)
* **P** = Principal amount (the initial sum of money)
* **r** = Annual interest rate (in decimal form, e.g., 5% = 0.05)
* **t** = Time period (in years)

## Features
* Input validation for principal, rate, and time.
* Real-time calculation of both the interest earned and the final balance.
* User-friendly interface.

## How to Use
1. Enter the **Principal Amount** you wish to invest or borrow.
2. Provide the annual **Interest Rate** as a percentage.
3. Specify the duration or **Time Period** in years.
4. Click "Calculate" to view the total interest accumulated.
